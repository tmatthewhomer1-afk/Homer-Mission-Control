# V3.7 Live Briefing

V3.7 adds a public-safe live briefing layer to Homer Mission Control.

## Weather
- Uses browser geolocation only after user permission.
- Coordinates are stored only in browser localStorage.
- Forecast data is requested directly from Open-Meteo.
- No weather API key is stored in GitHub.

## Headlines
- A GitHub Action refreshes public Google News RSS categories every four hours.
- The generated `data/headlines.json` file is safe to publish.
- Users can save or hide individual stories locally in the browser.

## Google Calendar
- V3.7 includes the calendar slot and secure-connection explanation.
- Actual calendar events are deferred to V3.8 because OAuth tokens and credentials must not be exposed in a public GitHub Pages repository.

## V3.8 target
A secure backend for Google Calendar plus cloud-synced Mission Control task data across devices.
